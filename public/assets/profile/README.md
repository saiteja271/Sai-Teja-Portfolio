# Profile Asset Configuration

This directory contains the professional portrait for **Venkata Sai Teja Sampati**.

## Asset Path:
`/assets/profile/portrait.png` (or `/assets/profile/portrait.jpg`)

## How to Replace:
1. Place your desired high-resolution photo in this folder.
2. Name it `portrait.png` or `portrait.jpg`.
3. Recommended aspect ratio: 3:4 or 4:5 (minimum resolution 800x1000px).
4. The portfolio's Hero component automatically detects and displays this asset with professional duotone/neutral treatment and graceful fallback.
